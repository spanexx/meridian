# Project Skills

Project-level agent skills live in `.agents/skills/<name>/SKILL.md` and follow the standard skill format: frontmatter with `name` + `description`, then the body (when to use, steps, checklist).

Rules (from AGENTS.md §5):

- After every iteration, **create or update a skill** capturing the lesson — the same mistake is never made twice.
- Use the `create-skill` skill to author new skills.
- Write the `description` so future agents auto-invoke the skill at the right moment.
- Commit skill updates together with the work that produced the lesson.
